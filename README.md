# 아트라상 편집기

원본 영상을 넣고 Codex·Claude Code에 **“롱폼 만들어줘”** 또는 **“쇼츠만 편집해줘”**라고 요청하는 편집 도구입니다. 원본 내용의 판단은 현재 대화의 AI가 하고, 포함된 엔진이 자막·컷·화면 구성과 원음으로 MP4를 만듭니다.

## 다른 노트북에서 시작

아래 문장을 Codex·Claude Code에 그대로 붙여 넣으세요.

```text
https://github.com/inhouseai-gif/atrass-editor
이 공개 저장소를 이 노트북에 내려받고 AGENTS.md와 outputs/atrass-editing-kit/PRODUCTION.md를 읽어 실행 환경까지 준비해줘. 내가 원본을 주면 롱폼 또는 쇼츠를 제작해줘.
```

GitHub 로그인 없이 내려받을 수 있습니다. ZIP을 받았다면 압축을 푼 폴더를 Codex·Claude Code에서 여세요. Python 3.12가 필요합니다. 담당 AI가 Apple Silicon에서는 `python3.12 atrass.py setup --asr mlx`, Intel Mac에서는 `python3.12 atrass.py setup --asr cpu`로 이 폴더 전용 환경을 준비합니다. 최초 음성 인식 모델 다운로드에는 인터넷과 디스크 공간이 필요합니다. 원본은 외부 전사 서비스로 보내지 않습니다.

준비가 끝나면 실제 파일 경로와 함께 요청합니다.

```text
/내/영상/원본.mp4로 롱폼 만들어줘.
/내/영상/원본.mp4에서 후보 10개를 고르고 가장 좋은 쇼츠 3개를 편집해줘.
```

사용자는 JSON이나 코드를 작성할 필요가 없습니다. 담당 AI가 전체 전사와 원본 화면을 보고 새 컷·디자인·후보를 결정한 뒤 `prepare → build → render`를 실행합니다. Codex·Claude 이용 환경과 원본 파일은 별도로 필요합니다.

## 포함 범위

A계열 공통 제작 엔진, 한글 폰트와 라이선스, 생성 삽화, 챕터 배경, 제작 절차를 포함한 공개 배포본입니다. 촬영 원본·참고 영상·시험 영상·연구 캡처·인증 정보·가상환경은 포함하지 않습니다. 과거 B계열 연구 재실행 자료는 이 배포본의 대상이 아닙니다.

기존 편집 결정으로 13분8초 전체 출력과 36개 관련 검사를 통과했습니다. 다른 실제 노트북, 새로운 촬영편의 반복 품질, 정확한 참고 스타일 일치와 직접 음성 청취는 아직 미검증입니다. `release_ready=false`이며, 공개 배포가 최종 품질 합격을 뜻하지 않습니다. 실제 사용 결과로 남은 관문을 검증합니다.
